Database Schema
[NEW] returns table
Tracks the high-level return request from a user.

id (UUID, PK)
order_id (UUID, FK -> orders)
user_id (UUID, FK -> users)
status (Enum: 'pending', 'approved', 'rejected', 'refunded')
refund_amount (Numeric)
reason (Text)
admin_notes (Text)
created_at, updated_at
[NEW] return_items table
Tracks specific items within a return request.

id (UUID, PK)
return_id (UUID, FK -> returns)
medicine_id (UUID, FK -> medicines)
quantity (Integer)
condition (Enum: 'good', 'damaged', 'expired')
[NEW] inventory_adjustments table
Immutable ledger of all stock changes.

id (UUID, PK)
medicine_id (UUID, FK -> medicines)
adjustment_type (Enum: 'restock', 'sale', 'return_restock', 'return_discard', 'damage', 'expired', 'correction', 'audit')
quantity_change (Integer) - Positive for additions, negative for reductions.
reference_id (UUID) - ID of the order or return causing the change (nullable).
performed_by (UUID, FK -> users)
reason (Text)
created_at
Backend Logic
